# Learning Management System

The application is being migrated incrementally from the original `OJT_Group1`
project. Each feature will be brought over in a small, verifiable slice instead
of copying the whole project at once.

## Requirements

- Node.js 18 or newer
- npm

## Local development

```sh
npm install
npm run dev
```

Create a local `.env` file from `.env.example` when configuring the backend API.
Do not commit `.env` files or credentials.

## Available checks

```sh
npm run lint
npm run build
```
