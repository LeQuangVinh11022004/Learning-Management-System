# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use GitHub's private vulnerability reporting or security advisory feature for
this repository. If private reporting is unavailable, contact a repository
maintainer privately through GitHub.

When reporting, include the affected area, steps to reproduce, potential impact,
and any suggested mitigation. Avoid including real user data, credentials, or
other secrets.

Please allow maintainers reasonable time to investigate before making details
public. This project does not currently promise a specific response or fix
timeline.

## Supported versions

Only the latest code on the default branch is currently supported with security
updates.
